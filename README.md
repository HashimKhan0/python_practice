# Python Practice

Personal notes and practice scripts covering core Python data structures, with short annotated examples of each operation.

| File | Covers |
|---|---|
| `lists.py` | Lists: ordered, mutable, allows duplicates. Creation, indexing, slicing, adding and removing, sorting, copying, list comprehensions |
| `tuples.py` | Tuples: ordered, immutable, allows duplicates. Creation, indexing, unpacking, conversion to and from lists |

Run any file with `python <file>.py`.
